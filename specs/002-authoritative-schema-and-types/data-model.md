# Evidence Model: Authoritative Schema and Types

T167 changes no production data model. This document defines the evidence entities used to select and audit a future schema/type-generation path.

## Status Vocabulary

| Status | Meaning in T167 |
| --- | --- |
| `PASS` | Directly recomputed evidence satisfies the bounded T167 criterion |
| `FAIL` | An executed check contradicts the criterion |
| `UNVERIFIED` | Material runtime, semantic, owner, external, or tool evidence was not obtained |
| `DEFERRED` | Execution is intentionally assigned to a later authorized task |
| `NOT_ADMITTED` | The artifact is known and hash-bound but is not part of the authoritative source set |
| `EXCLUDED` | The artifact was evaluated and rejected as a source for a stated reason |

`DEFERRED` never implies eventual success. `NOT_ADMITTED` never implies semantic review. A timestamp check can be `PASS` for its own heuristic while semantic parity stays `UNVERIFIED`.

## Entity: LaneIdentity

Represents the immutable pre-write boundary authorized by R0.

| Field | Type | Required invariant |
| --- | --- | --- |
| `path` | absolute path | Exact clean execution lane |
| `branch` | string | Exact Codex lane branch |
| `head`, `base`, `origin_main`, `remote_origin_main`, `merge_base` | 40-hex SHA | All equal the authorized commit before writes |
| `tree` | 40-hex SHA | Exact authorized Git tree |
| `divergence` | string | `0/0` before writes |
| `upstream` | enum | `ABSENT` |
| `remote_branch` | enum | `ABSENT` |
| `lock` | object | Locked, with expected lane ownership/reason |
| `normal_status_count`, `ignored_status_count` | integer | Both zero before writes |
| `package_lock` | ArtifactBinding | Exact tracked file binding |
| `workspace_descriptor` | ArtifactBinding | Exact external descriptor binding and mode |
| `doctor` | CheckResult | Exit 0 and scoped `GO` before writes |

Any pre-write mismatch transitions the task to `WAITING_FOR_OWNER`; it is not repaired inside T167.

## Entity: ArtifactBinding

Represents one file or exact file set.

| Field | Type | Rule |
| --- | --- | --- |
| `path` | string | Absolute path for external evidence; repository-relative path for lane content |
| `source_lane` | enum | `CLEAN_LANE`, `DIRTY_UMBRELLA`, or `EXTERNAL_DESCRIPTOR` |
| `git_state` | string | Directly observed tracked/untracked/modified/absent state |
| `bytes` | non-negative integer | Recomputed from exact bytes |
| `sha256` | 64-hex string | Recomputed from exact bytes |
| `admission` | enum | `ADMITTED`, `NOT_ADMITTED`, `EXCLUDED`, `READ_ONLY_TARGET`, or `PROVENANCE_ONLY` |
| `owner_task` | string | Task allowed to change or admit the artifact |
| `reason` | string | Evidence-backed classification, not a generic label |

For a file set, `count`, Git tree, canonical format, and aggregate SHA-256 are also mandatory. A symlink, index/working-tree byte mismatch, status drift, or membership drift invalidates the set.

## Entity: SchemaSourceSelection

The current T167 decision consists of:

1. `LaneIdentity` matching R0.
2. One admitted clean `supabase/config.toml` binding.
3. One admitted exact 80-file tracked migration set.
4. One read-only generated target binding.
5. Explicit dirty candidate and dirty config exclusions.
6. Future execution mode `DISPOSABLE_LOCAL_ONLY`.
7. Selection result `PASS` only if all bindings and scope assertions pass.

The selected current migration set is versioned evidence, not a floating directory. T168 admission requires a new selection revision before replay.

## Entity: DeferredExecutionGate

| Field | Replay value | Generation value |
| --- | --- | --- |
| `owner_task` | T169 after T168 admission | T169 |
| `status` | `DEFERRED` | `DEFERRED` |
| `verification` | `UNVERIFIED` | `UNVERIFIED` |
| `target` | Fresh disposable local Supabase | Successfully replayed local Supabase |
| `seed_allowed` | false | not applicable |
| `remote_allowed` | false | false |
| `command` | `supabase db reset --local --no-seed` | `supabase gen types typescript --local` |
| `success evidence` | Exit 0, exact reviewed set, no remote target, retained local logs | Exit 0, captured generated bytes/hash/diff, semantic/freshness checks |

The two commands form an ordered future transition:

`SOURCE_REVIEWED` → `LOCAL_REPLAY_VERIFIED` → `LOCAL_TYPES_GENERATED` → `SEMANTIC_AND_DIFF_VERIFIED`

T167 ends at `SOURCE_REVIEWED_CURRENT_BASELINE`. It does not enter any later state.

## Entity: CheckResult

| Field | Type | Rule |
| --- | --- | --- |
| `command` | string | Exact command actually executed, or explicit `NOT_EXECUTED` |
| `exit_code` | integer or null | Null only for unexecuted future commands |
| `result` | status | Must match observable evidence |
| `scope` | string | Exact property proved |
| `limitation` | string | Required when the check is heuristic or partial |

## Entity: PlatformImpact

Exactly five rows are required:

- Web/Vite
- installed PWA
- Android/Capacitor
- iOS/WKWebView
- Desktop/Tauri

Each row records `STATIC_SHARED_SCHEMA_CONTRACT_ONLY`, no runtime change, runtime evidence `UNVERIFIED`, and a later verification obligation after admitted schema/type changes. Store/release, accessibility, performance, security/privacy, testing, and operations are separate matrix dimensions and cannot inherit a platform `PASS`.

## Entity: T167Receipt

The ignored JSON receipt contains:

- task/schema version and creation timestamp;
- R0 receipt binding and explicit waiver limits;
- pre-write lane identity;
- source-selection bindings and decision;
- dirty RED and clean timestamp observation with semantic limitation;
- exact future command strings marked not executed;
- tool-availability and replay/generation gates;
- platform and implied-requirements matrices;
- prohibited-action assertions;
- changed-path and invariant bindings;
- rollback and remaining gates;
- final scoped result.

The receipt must validate as a JSON object. It is evidence for T167 source selection only and is not a migration, schema dump, production receipt, release approval, or runtime proof.

## Invariants

1. No admitted source may originate only from the dirty umbrella.
2. A known hash does not change `NOT_ADMITTED` to `ADMITTED`.
3. Replay cannot transition from deferred until T168 completes migration admission and the exact clean-lane set is rebound.
4. Generation cannot transition from deferred until local replay succeeds.
5. Any remote target, seed execution, source-set drift, index/working-tree mismatch, symlink, or prohibited-path change invalidates the selected execution attempt.
6. T167 `PASS` is scoped to source selection and documentation integrity only.
