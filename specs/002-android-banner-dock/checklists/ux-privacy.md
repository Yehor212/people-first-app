# UX, Privacy, and Failure Checklist

- [x] No banner on empty-today/rest Habits state.
- [ ] No banner on create, library, action, detail, drawer, command palette, challenge, mindful, focus, auth, or modal surfaces.
- [x] No banner while IME is visible or app/document is inactive.
- [x] Consent revoked, non-adult, UMP denied, grace incomplete, entitlement unknown/premium, and account switch all remove the view.
- [x] Same-day bad/terrible protects the full local day.
- [x] Dock is reserved before native visibility and cleared after failure/no-fill/removal.
- [ ] Last habit and actions stay reachable with gesture and three-button navigation.
- [ ] Portrait, landscape, split-screen, `en`, `ar`, `he`, large font, and screen-reader semantics are checked.
- [x] QA screenshot visibly shows a Google test ad; no live ad is clicked or requested intentionally.
- [x] Production build contains no sample IDs, testing flags, or mock runtime data.
