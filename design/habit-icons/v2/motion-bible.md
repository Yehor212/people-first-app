# V2 Habit Icon Motion Bible

## Contract

- No emoji final icons.
- No generated final icons.
- Every icon has idle, press, complete, disabled, and reduced states.
- Idle loop: 1.8s-3.0s.
- Motion target: 60fps.
- Reduced motion: meaningful still SVG.
- Runtime must pause offscreen icons and bypass animated runtime when reduced motion is active.
